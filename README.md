# Miura-Solar-Panel-CAD

---

## Objectives

- To study and implement the Miura fold in solar panel design
- To reduce volume during transportation and storage
- To ensure smooth and reliable deployment
- To explore applications in satellite and portable systems

---

## Tools and Technologies

- Autodesk Fusion 360 (for CAD design and simulation)
- Markdown (for documentation)
- FPDF (for PDF generation)

## Future Work

- Add automation using actuators or shape memory alloys
- Experiment with flexible photovoltaic materials
- Perform real-time deployment and energy output testing
